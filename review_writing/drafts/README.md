## 使用规则

- **边写边精读**：先以现有证据写可成立的段落 → 列出需要改变结论的未核事实 → 精读对应论文原文 → 修订原段落和证据台账。
- **区分来源级别**：原文定向精读、正式摘要、机构资料不是同一等级的核查，更不能任一等同作者已经逐条复核。
- **避免罗列**：正文先建立比较对象和口径，再讨论代表研究做法及其适用限制。
- **保留结构**：第3章仍是3.1–3.4四节，第1章和第5章未被这次草稿替换，原有文献映射和检索表保持不变。
- **不乱填性能**：当前不能据本库没有某项论文直接断言领域空白，也不能比较不同任务/硬件/基准的算法排名。
- **正式排版**：本稿暂以[@O90]等BibTeX key作内部引用，目标期刊确定后转换为投稿格式。
