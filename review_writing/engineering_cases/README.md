## 数据结构与读法

案例按**能力/事件**编号为EC001—EC070。同一公司可以有不同案例，例如Starlink既有自动规避又有星历共享和壳层维护，NASA Starling既有四星自主运行又有与Starlink进行的跨运营方模拟险情试验。这不会被误算为多个独立星座。

成熟状态独立于P0/P1/P2优先级：**P0**表示对当前论文主论点的重要程度较高，**P1**表示专题或典型比较，**P2**用于背景或未来计划，不能解释为“P0全部经过作者技术全文验收”。

特别需要保留的反向/负面证据包括：EC031（Axelspace 7星批次4星高速下传永久故障）、EC040（ELSA-d自主捕获被中止）、EC042（ADRAS-J近距接近后安全中止）和EC047（Impulse姿态控制异常导致主推力计划无法执行）。真实工程系统的安全退出、降级运行与不能交付，比单纯列成功卫星发射数量更能够帮助第3.3和第4章形成可信的评价。
