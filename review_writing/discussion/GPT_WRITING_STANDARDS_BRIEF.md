# 给GPT的写作准则讨论说明

## 讨论目标

我们正在准备一篇关于大型卫星星座智能管理与调度的综述。请基于本目录材料，帮助制定可操作、可检查的写作准则和质量标杆，并解释每条准则怎样用于我们的具体章节。

当前阶段是检索、分类和证据映射。我们已形成5章骨架和148条候选文献库，尚未完成全部全文精读、最终纳入、正文和目标期刊选择。

| D02 | 文章类型与检索报告 | 选择适合的综述类型，规定数据库、时间范围、检索式、去重和筛选记录；声明须对应实际完成工作。 |
| D03 | 目标期刊与组织标杆 | 给出目标期刊候选及核查事项，选择需要阅读全文对照的代表综述，说明比较理由。 |
| D04 | 文献纳入与引用角色 | 规定核心、背景、异场景参照和待核材料的用途，处理会议稿、预印本与期刊版关系。 |
| D05 | 分类框架和术语 | 统一层级、对象、状态、任务、资源、约束、智能方法与闭环接口的定义。 |
| D06 | 章节和段落写法 | 给出五章分工、第三章四节的共同写法及比较段落模板，说明重复内容如何处理。 |

| D09 | 综合评价与展望 | 规定如何由已确认的模型限制和证据不足推导可检验研究问题，避免把本库覆盖不足直接当研究空白。 |

| D12 | 完成判据与审稿自检 | 给出进入正文、技术比较、提交前检查所需条件，并标出当前已完成和待完成事项。 |


## 本次讨论的证据边界

- 148条是候选文献库，不能自动当作148篇最终引用或全文已核查。
- DOI匹配确认文献身份，技术判断仍需一手全文和支持位置。
- 部分研究来自单星、深空、地面站或一般多代理场景，映射表已标注迁移条件。
- 理论、仿真、软件、板级或在环、飞行证据分别记录，不从局部验证外推完整大型星座闭环。
- 本目录的写作任务和未来问题是拟议分析框架，尚需文献证据支持。
- 目标期刊、检索截止期、篇幅、引用格式和最终写作规则尚待讨论，不补造已经确定的要求。
