# 决策表述与术语界定检查表（v1.1）

适用于摘要、第2章的问题定义、第3章的方法说明、第4章的比较判断，以及需要独立阅读的图表。先看段落逻辑，再逐句检查；未完成的项目保留具体原因。模板不是对现稿已经通过检查的声明。

| 检查项 | 需要确认的内容 | 常见问题及处理 |
| --- | --- | --- |
| 具体对象 | 读者能指出哪颗或哪类卫星、哪项请求、哪种活动或哪项资源 | “成员协同配置能力”需还原具体对象与操作 |
| 术语首次定义 | 窗口、接触、容量、活动等在本语境的含义明确 | 不默认读者了解原论文的专门定义 |
| 已知条件 | 输入来源、已知时刻和已做的筛选清楚 | 几何可见不能自行扩写为姿态、能源等全部可行 |
| 待决定内容 | 清楚区分卫星选择、时间段选择、开始时刻、顺序和资源分配 | 不能用“安排时间”包办不同变量 |
| 时间要素 | 开始、结束、持续时间与顺序的角色分别明确 | 持续时间是固定还是可调、是否枚举机会，按原模型说明 |
| 动词与操作 | 选择、排序、分配、保留、撤销、修复分别作用于明确对象 | 把“完成配置”展开到实际决定 |
| 可行性范围 | 可行相对于哪一组约束，是否仍有后续检查 | 不把局部或简化模型的可行解写成完整运行保证 |
| 句段可理解 | 信息由清楚的句子、上下文或紧邻表格交代 | 过密时拆句，不机械把全部字段塞进一句 |
| 原文一致 | 解释与原文变量、定义、版本及实际核读范围一致 | 未核清时记录缺口，不替论文补模型或步骤 |

## 每段留痕模板

- 稿件位置及稳定命题ID：待填。
- 具体对象：待填。
- 已知条件及输入来源：待填。
- 待作出的决定：待填。
- 首次使用的术语与含义：待填或不适用。
- 时间要素的输入／变量／不适用状态：待填。
- 已检查及尚需检查的约束：待填。
- 原句、修订句与修改理由：待填。
- 来源定位或本文示意／归纳的身份：待填。
- 作者阅读反馈及尚未关闭项：待填；不得默认已经确认。

## 应用到后续精修

第2章先使具体对象、输入与决定清楚；第3章据此解释算法怎样产生选择；第4章说明方法比较改变了哪些条件。摘要和图表随后检查相同术语，避免正文已经具体、摘要仍使用无法对应实际操作的概括词。原分批计划的进度按真实交付记录更新，不因本检查表建立而增加精读或改稿完成计数。
