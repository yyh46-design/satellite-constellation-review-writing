# 精读成果与正文主线的重新整合

2026-10-21。根据作者对V3.3的反馈形成：新增精读文献应推动主线及章节论证，而不能主要停留在末尾增补。本文是结构诊断和下一版重写依据，不是已完成的V3.4正文。

## 一、对V3.3的判断

**V3.3完成了有用的局部补强，尚未充分完成由新增精读推动的全文重组。** 它沿用V3.2的五章骨架，第3章仍以优化、启发式、学习开篇，再列多星协调、状态驱动调整及新增3.6安全机动；第4章补入恢复与采用。这使新材料主要补充旧框架，尚未共同决定主要技术问题及其比较次序。

对照本阶段B11—B20的97篇记录，14篇进入V3.3书目，83篇尚未进入。按先前十项写作接口的代表论文逐项核对，执行能力与任务资源、构型与成员分配、风险定义、信息时效、学习与安全层五组的指定候选均未被引入。**这不表示正文完全没有讨论这些主题**：V3.3使用了其他证据，也有相关综合；该核对准确说明的是原写作映射尚未被系统吸收。完整逐篇及逐接口结果分别见[97篇整合表](LITERATURE_REINTEGRATION_PLAN.csv)和[十项接口覆盖表](V33_WRITING_TOPIC_COVERAGE.csv)。

文献数量只是可见症状。需要调整的核心是每节先回答什么问题、用哪些研究构成相互比较，以及结论如何回答综述问题。V3.3有80项书目和完整正文，不等于这次主线整合已经充分完成。

## 二、下一版的实质主线

题名暂沿用《大型卫星星座智能运行管理中的规划与协同决策方法综述》。建议将中心问题具体化为：

> 面向业务需求、资源竞争及运行扰动，大型卫星星座如何形成任务与资源安排，协调成员行动并维持安全，在异常后更新计划、恢复能力和接续业务？

全文围绕三条有具体研究对象的技术线组织：**任务与资源的协同规划 → 多星协同与安全决策 → 动态重规划与任务恢复**。“形成—协调—采用更新”继续作为贯穿各线的分析维度，具体说明每类方法的输入、选择、协调、执行及反馈。

这是一套综述的组织判断，不主张上述研究共同实现了同一大型星座闭环。近距离编队、单受控航天器和地面多智能体材料应分别服务于机制解释，保留规模及验证边界。任务与资源调度的算法深度继续保留；优化、搜索、学习、规则等在各类问题内比较。

## 五、实际重写次序和可检查的结果

1. 按上述问题形成章节证据提纲，将原段落标为保留、迁移、重写、合并或删除，避免直接在旧3.6后追加更多段落。
2. 先重写第3—5章，每个比较段说明共同问题、机制差异、信息与动作条件、证据及局限。28篇是优先候选，进入正文前仍须复核相关原文。
3. 再改第2章和第6章，使变量、指标和综合结论与主体一致；最后回修引言、摘要、题名适配性及结论。
4. 逐篇登记采用位置和原因。正文出现的引用应承担事实、比较、边界或背景职责；未使用的阅读保留为储备，不虚报已经吸收。
