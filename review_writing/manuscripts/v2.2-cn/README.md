## 数量及范围

参考资料由121项调整为94项：84篇学术文献和10项官方工程资料。保留原目录77篇已有定向正文核读记录的学术来源；34篇未核读正文的学术来源退出本版引用；另纳入B10补充来源7篇。ALT08复用原[119]，没有重复计数。英文原标题及非官方中文译名保留在文末。

这次重写35个既有区块，新增9个区块。总计132个段落/表格区块有映射；映射中“本文归纳”与原研究的具体结果分开标识。图表和正文按首次出现顺序重新编号；E###稳定来源键不随可见编号变化。

本轮只补核原[18]、[71]、[96]的关键正文位置及6个实际页面，不增加既有目录精读数量。原目录仍为77/111篇定向正文核读、34篇待核；B10目录外已读10篇的历史计数不变。撤下引用不等于取得原文或关闭缺口，正式版本配对关闭数仍为0。

正文（含摘要、图表，排除文献表）的中文汉字计数由12882增至14141，约增加9.8%。删掉列表性铺陈后补写了条件比较，因此本版是论证重组，并非整篇压缩。Word共23页；正文与结论结束于第16页，参考文献随后开始。排版页数不是期刊的篇幅合规判断。

## 证据使用

正文依据可以是出版社PDF、完整HTML、机构接受稿或作者预印本。各版本按实际身份使用，不因DOI正确就标为正式全文。SOURCE_MANIFEST及最小标识检查清单中的verification字段仍保留未终核状态；实际AI定向核读/打开情况查历史记录、B10_recheck和current_core_recheck，不能把机器检查通过当成人工科学确认。

34项撤下来源不再承担方法结论、表格或分类覆盖依据；新补充论文承担的是重新写出的论点，不能继承旧论文的专属算法或性能结论。本文不据现有样本宣称覆盖全部研究，也不从“未取得”推断“没有人研究”。
