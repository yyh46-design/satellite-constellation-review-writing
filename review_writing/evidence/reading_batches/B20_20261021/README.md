## 形成的写作判断

1. **将构型分配与安全机动分开评价。** L024给出单星代价与槽位分配的连接，L063加入终态被动安全几何；二者都需要另查转移全程的成对安全条件。
2. **把规避后的任务恢复写进评价。** L049将维护周期纳入双星规避，L042和L050将轨道保持与规避联合设计。L042明确存在中途越框情况，说明终态恢复不能替代全程约束。
3. **区分规划更新与实际闭环验证。** L043给出初值、执行约束和后验传播的流程；L050的OD更新是合成步骤，可解释信息更新如何改变采用决策，尚不能称为真实导航闭环。
4. **保留多星协同证据的缺口。** L019与L049仍为双星案例；L063多星几何扩展不等于大星群协议验证。不能因方法含“formation”便归入已验证的大规模协同安全控制。
