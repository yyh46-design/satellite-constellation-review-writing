## 对下一轮写作的帮助

1. **维持与任务需求相连。** L004把观测几何、推进能力、寿命和可测量窗口连起来；L008说明最优动作仍要经过物理可执行性筛选。
2. **协同通信有执行成本。** L018把相对轨道预测接到载荷和姿态跟踪；L071展示配置通信与近距安全感知的分工，但其后续澄清未读，暂不采用安全定理。
3. **把安全指标定义写清。** L030、L033、L034、L036分别提供条件最大概率、轮廓积分、非高斯通量积分和瞬时概率近似的比较材料；不能把它们放在同一个无条件“安全率”指标下。
4. **保留反例与边界。** L015显示线性协方差结果并非始终保守；L036存在低估；L014属于日心部署，应限制主综述中的用途。

以上为阅读者的组织建议。建议3.6.1/3.6.2/3.6.3仍是待增写位置，v3.2目前并没有这些小节；现有3.4、4.3、4.4可在下一轮修订时承接。本批未改稿。
